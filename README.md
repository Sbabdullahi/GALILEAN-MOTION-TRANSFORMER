A re-engineered and fully reproducible version of the Galilean Motion Network (GMN) for skeleton-based hand-gesture recognition (LeapGestureDB, LMDHG). It is a research prototype, **not a medical device**.

> **Every number in the research is generated by this repository from saved per-run predictions.**

## What is new in v2

| Component | v2 |
|---|---|
| Kinematic layer | **Galilean-frame convolution**: velocity and acceleration are least-squares estimates from every input window on *physical* coordinates. A learned kernel acts on the co-moving-frame residual, which is exactly invariant to translation and constant-velocity drift (`test_residual_stream_galilean_invariant`). The estimates are passed on as interpretable read-outs, together with a signed **chirality** term for clockwise/counter-clockwise motion |
| Orientation | **Palm-frame stream** built from the measured palm normal and hand direction; rotation-invariant by construction (`test_palm_stream_rotation_invariant`) and evaluated under 0°–180° sensor rotation |
| Pooling | **Class-query attention pooling** (one query per class, giving per-class temporal evidence) |
| Evaluation | **5-fold subject-wise CV × 3 seeds**; BiLSTM, Transformer, ST-GCN, v1 and two controls (standard conv; finite-difference v, a) **re-implemented and trained with the same script** |
| Statistics | **Corrected resampled t-test** (Nadeau & Bengio 2003) with Holm correction; Wilcoxon as a check |
| Trust | ECE/NLL/Brier and reliability diagrams over the whole test set; MC-Dropout entropy and mutual information; **risk–coverage and a validated deferral policy** |
| Explanations | Integrated Gradients over all classes and folds, with a completeness check and a **model-randomisation sanity check** |
| LMDHG | Same design and recipe, ground-truth segments, standard 1–35 / 36–50 sequence split, test set only |

See [`CHANGELOG.md`](CHANGELOG.md) for the full list.

## Layout
```
gmn/                 library
  data_leap.py       parser, cache, per-sample geometric normalisation, subject-wise split files
  data_lmdhg.py      LMDHG ground-truth segments and streams
  geometry.py        least-squares kinematics, palm frame, quaternions, rotations
  layers.py          GalileanFrameConv, class-query pooling, encoder layer
  models.py          GMN v2, ablations, baselines, faithful v1 port, registry
  augment.py         augmentation (identical for every model)
  train.py           one run = (model, fold, seed); saves logits, metrics, MC-Dropout, deferral
  metrics.py         metrics, temperature scaling, ECE, risk–coverage, deferral policy
  stats.py           aggregation, CIs, corrected resampled t-test, Holm, subject bootstrap
  analysis.py        rotation robustness, IG + sanity checks, kinematic read-outs, profiling
scripts/
  data_audit.py  sweep.py  run_cv.py  run_analysis.py  make_report.py
  run_lmdhg.py   make_lmdhg_report.py
tests/               unit tests for every property + synthetic data generator
docs/                MODEL_CARD
legacy/              the v1 code, unchanged, for reference
```


## Reproduce step by step
```bash
git clone https://github.com/Sbabdullahi/GALILEAN-MOTION-TRANSFORMER.git && cd GALILEAN-MOTION-TRANSFORMER
pip install -r requirements.txt
pytest -q tests

```
A smaller first pass is possible:
```bash
python scripts/run_cv.py --data_path ... --results ... --models gmn gmn_fd_control gmn_stdconv --seeds 0
```

**Compute budget.** The full grid is 15 models × 5 folds × 3 seeds = 225 runs. On a T4 this is roughly a day of GPU time, spread over several Colab sessions. A sensible order:
1. the main table (`gmn gmn_fd_control gmn_stdconv transformer stgcn bilstm gmn_v1`, 3 seeds);
2. the ablations with `--seeds 0`;
3. extra seeds for the ablations.


## Data
- LeapGestureDB: Ameur et al. (2016, 2021), available from the authors' site. Expected layout: `<root>/<subject folder with a number>/G<k>_*.txt`.
- LMDHG: Boulahia et al. (2017), `DataFile1.mat … DataFile50.mat`. On first use, run `python -c "from gmn.data_lmdhg import inspect_mat; print(inspect_mat('DataFile1.mat'))"` and check that the variable names match `gmn/data_lmdhg.py::_read`.

The split files (`results/splits.json`) are released so that other groups can use exactly the same subject partition.

## Responsible use
See [`docs/MODEL_CARD.md`](docs/MODEL_CARD.md). The model proposes commands, and a person confirms any command below the validated confidence threshold or on the clinician-defined always-confirm list. There has been no clinical, or real-time evaluation.
